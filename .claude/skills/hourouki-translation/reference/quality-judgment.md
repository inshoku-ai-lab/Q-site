# 品質の判断基準 — 監督役（呼び出し側）の手引き

翻訳エージェントは**1話だけ**を見る。シリーズ全体の一貫性と、事実の検証は**監督役の仕事**。
このファイルは、Ep 0〜343 を監督してきた中で確立した判断基準をまとめたもの。

文体そのものの規則は `voice-bible.md`、訳語は `glossary.md`、人物は `arc-map.md`、
物語の文脈は `story-so-far.md`。**ここに書くのは「どう判定するか」。**

## 2. 翻訳上の判断（実際に下した裁定の蓄積）

### 2-1. 原文を「直さない」もの

- **著者の曖昧な記憶や、素朴な思い違いは直さない。**
  「イージーネットとかだったと思う」→ `easyNet, I think`（実在の店名 easyEverything に直さない。Ep 324）。
  「イギリスのATM会社」→ そのまま（正しくは銀行だが、著者の思い違いごと訳す。Ep 308）。
  「国営の放送局」→ `the state broadcaster`（BBC は国営ではないが、著者の言い方。Ep 322）。
- **原文自身の矛盾は、訳者が辻褄を合わせない。**
  スクワット・ハウスを「不法占拠」と説明しながら「合法／半合法的に占拠」とも書く（Ep 309）→ 両方残す。
  **話をまたぐ矛盾**（ゴアギルの36時間と48時間、皿洗いの週4時間と週25時間）→
  原文どおりに訳し、`migration/reports/source-issues-ja.md` で著者に報告する。
- **時代の枠組みを現代化しない。**2000年当時の見方や言葉づかいのまま訳す（Ep 316）。
- **原文にある感嘆符は残す。**禁止されているのは「増やす」ことだけ（Ep 257・308）。

### 2-2. 原文が語を書き分けていれば、英語でも書き分ける

著者は近い意味の語を意図的に使い分けている。**統合すると著者の区別が消える。**

| 別語として保つ | 理由 |
|---|---|
| 悪循環（vicious cycle）／負のスパイラル（downward spiral） | 隣接する話で著者が語を変えている |
| カースト（caste system）／階級（class system） | Ep 253 と Ep 272 |
| 不法侵入（trespass）／不法占拠（illegal occupation） | Ep 264 と Ep 311 |
| 癒着（in bed with）／つながりがある（had ties to） | 癒着は腐敗を指す強い語 |
| ペーパーアシッド（paper acid）／LSDの紙片・小片 | 原文がカタカナ語を使っていない |
| トビ（the high）／トリップ（trip） | trip を禁じたのは トビ だけ |
| 運び屋（courier）／密輸（smuggling） | Ep 223〜241 |
| 水晶（quartz）／クリスタル（crystals） | 語感が違う |

### 2-3. 同じ語でも、意味が変われば訳し分ける

**ゴア人**：Ep 99・113 は現地のインド人（Goans）、**Ep 256 以降はゴアに集まるパーティー族**（Goa people）。
Goans と訳すと意味が反転する。**2人のエージェントが独立に同じ結論に達した**ので確定した。

### 2-4. 固定しない語

**語調や文脈で揺れるのが正しい語は、全体では固定しない。ただし1話の中では揃える。**

- ダサい → `lame`（強い切り捨て）／`uncool`（軽い気まずさ）
- 濃い／濃さ → 話ごとに選ぶ（intensity、sheer character など）
- ブラウンシュガーの摂取動詞 → 話ごとに違う（吸う、混ぜる、炙る）

⚠️ **1話から一般化して固定すると、次の話で誤りになる。**これで3回失敗している（ブラウンシュガー、空手家、ダサい）。

### 2-5. 原文の繰り返しは残す

著者の繰り返しは効果として置かれている。英語で言い換えて消さない。
不法侵入×4（塀を越えるだけの行為に刑法用語を当てる可笑しみ、Ep 264）、最先端×2、激安×3。
**ただし英語で吃音のように読めるだけの反復は、意味を落とさずに整理してよい**（Ep 336 のディジェリドゥ×2）。

### 2-6. 足さない

- **原文が説明していないものに説明を足さない。**（Ep 261 の "getting sick without meaning to" は逆翻訳で捕まった）
- **原文が主語を書いていない文に主語を補うときは、原文が支える最小限。**
  性別の分からない人物に he/she を付けない（Ep 322 の「スタッフのような人」→ the staffer）。
- **グロスは初出のみ。**原文自身が直後に説明している語には足さない。
- **著者の方針（2026-10-01）：アメリカの読者に意味が通じない箇所には、短い補足説明を足す。**
  Ep 519 の "the apple-and-honey sweetness of Japanese boxed curry" を著者が承認。上の「足さない」は**話の中身**（原文に無い事実・感情・解釈）に掛かる規則で、
  文化的な前提知識を補う短いグロス（voice-bible §3-6）はこれに当たらない。全話を洗い出して足した（`<scratchpad>/gloss-brief.md`）
- **作品名を原文が出していないなら英語でも出さない**（カメハメ波、界王拳で Dragon Ball と書かない）。

### 2-7. 数字と通貨

- 数字は原文どおり。丸めない。
- 円→ドルは**同じ数値の2回目以降に付けない**。金額が違えばそれぞれ1回付ける（voice-bible §3-5）。
  原文がすでに二重表記（「５０ルピー（１５０円）」「１ポンド（約２００円）」）ならドルへ直行。
- 単位はメートル法を先、ヤード・ポンド法を括弧に。初出のみ。

### 2-8. 英国編（Ep 305〜343）の例外

地名・制度・著者が観察した英国の生活は、**本物の英国の名称**のまま（the Metropolitan Police、a twenty-pound note、Glastonbury Festival）。
**語り手自身の語彙と言い回しは米語のまま**（neighborhood、potato chips）。モロッコ編では標準の米語に戻る。

## 3. 3人査読の「2人以上」規則の運用

- **1人だけの指摘は採用しない。**（過剰修正を防ぐ仕組みで、実際に何度も効いた）
- **2人以上の指摘でも覆してよい条件**：
  1. 正確さと衝突する（原文がそう書いている）
  2. 用語表で固定された語
  3. **コーパスに根拠がある**（Ep 308 は感嘆符を「浮く」と言われたが、原文に！があり、訳了19本に先例があるとして残した）
- **査読者は人物の同定に無力。**「同一人物だから揃えろ」は2ラウンド連続で全員一致し、2回とも誤りだった。
- **エージェントの報告で、何を採用し何を退けたかを必ず読む。**退けた理由が原文か用語表を指していれば健全。
  「自然さ」だけを理由に原文の要素を落としていたら、差し戻す。

## 4. 監督役が自分で検証すること

**エージェントの主張、取得エージェントの報告、そして自分の記憶を、鵜呑みにしない。**
以下は、検証せずに信じて実際に誤った例。

| 何を | どう確かめる | 実際にあった誤り |
|---|---|---|
| 会員限定マーカーの位置 | `scan_src.py <lo> <hi>` | 取得エージェントの「314/318/322 は記事の途中」をそのまま指示に書いた。途中は 314 だけだった |
| 人物の同定 | 原文を grep し、関係性の記述を読む | 同じ T が、スクワットの友人と大阪出身の他人の2人だった（Ep 317 のエージェントが指摘） |
| 誤字の主張 | 同じ話、できれば同じ文に正しい形があるか | 裏が取れたものだけを著者に報告した（Ep 330・341 は同じ話・同じ文に正しい形があった） |
| 「Ep X がこの語を所有する」 | その話の原文に本当にその語があるか | Ep 290 のエージェントは Ep 288 が「絶対時間」を所有すると言ったが、Ep 288 の原文にはその語が無かった |
| 「校正記録に載っていない」 | `corrections_for.py <ep>` | 取得エージェントの独自集計が誤りで、実際には記録されていた |
| 自分の過去の判断 | 規則の原文を読み直す | 円→ドルを「1話1回」と誤読して Ep 262 を直してしまい、後で戻した |

**エージェントが監督役の指示に反論してきたときは、たいてい正しい。**
（ブラウンシュガーの動詞、空手家、Ｔの導入話、会員限定マーカーの位置、自分の宛先の取り違え。いずれもエージェント側が正しかった。）
反論が来たら、原文で確かめてから採否を決める。

## 5. バッチごとの横断チェック

エージェントは自分の話しか見ていない。**隣接する話どうしの割れは、組み立ての後に監督役が grep で拾う。**

```bash
P=migration/posts-en
# 1. 隣接話で訳語が割れていないか（例：変わり者）
grep -oh "eccentric\|oddball" $P/27[345]-*.md | sort | uniq -c
# 2. 英語本文に日本語の字が残っていないか（画像パスとフロントマターを除く）
python3 - <<'PY'
import glob,re
for p in sorted(glob.glob("migration/posts-en/*.md")):
    b=re.sub(r'!\[[^\]]*\]\([^)]*\)','',open(p,encoding="utf-8").read().split("---\n",2)[2])
    c=set(re.findall(r'[ぁ-んァ-ヶ一-龠〇○]',b))
    if c: print(p.split("/")[-1],"".join(c))   # Ep 67 の 糖 は正しい
PY
# 3. 性別の違う同じイニシャルがいるアークでの代名詞監査（例：T）
for f in $P/3[0-4]*.md; do grep -q "\bT\b" "$f" && grep -q "\bshe\b\|\bher\b" "$f" && echo "$f"; done
# 4. 会員限定マーカーの索引と本文の位置の一致は qa_check.py が ERROR で見る
```

割れが見つかったら、揃える方向は：
1. **その語を導入した話が所有する**
2. **すべての用法で無理が出ない語を選ぶ**（例：変わり者 は、抽象名詞 eccentricity を作れる eccentric）
3. 本文の修正は `<scratchpad>/agent-out/ep-NNN.body.md` に入れてから組み立て直す

## 6. 逆翻訳の使い方

逆翻訳は**著者のため**のものだが、**監督役にとっても最良の品質チェック**になる。
逆翻訳エージェントが「曖昧」「訳し戻しにくい」と報告した箇所は、**原文と照合する**。

実際に捕まったもの：
- 原文に無い補足説明（Ep 261）→ 削除
- 同じ金額への二重のドル表記の疑い（Ep 262）→ 規則を確認した結果、別の金額だったので残した
- 語感のずれ（Ep 261 の「人付き合い」が "experience of people" になっていた）→ 修正

逆翻訳の**後**に英語を直した文は、逆翻訳側に「ブラインドではない」と明記する。

## 7. 著者への報告

- 著者は英語の自然さを判断できない。**報告は必ず日本語**で、判断材料（原文の該当行、他の話の該当行）を添える。
- **日本語原文は一切直さない。**直すのは著者。
- 原文の誤字は、正しい意味で訳してから報告する。**矛盾**（どちらが正しいか分からない）は原文どおりに訳して報告する。
- 集約先は `migration/reports/source-issues-ja.md`。

## 8. Ep 339〜520 で下した裁定（2026-09）

- **エージェントが足した「To be continued...」を削る。**原文に「つづく／続く」が無い話に付けた例が 366・454 にあった。
  バッチごとに `grep -c "つづく\|続く"` と `grep -c "To be continued"` を話ごとに突き合わせる（漢字の「続く」を見落とさない）
- **イギリス人＝English**（an Englishwoman 等）。390・392・394 で British が出たので直した。glossary §6-9
- **人物カードの誤りは20話分を誤らせる。**ゴア編のカードに Gandalf がいたのは誤り（初出は Ep 357）。J を「同僚」としたのも誤り（小さな小屋の支配人）。調査エージェントの報告はエクスポートではなく Notion 原文で裏取りする（Ep 360 は Notion で著者が R→J に直していた）
- **同じイニシャルの男女**：山小屋編の K くん（男・18）と K ちゃん（女・30代）。英語はどちらも裸の K なので代名詞を原文の接尾辞で決める。性別の語が原文に無い人物（465・466 の N）には he/she を付けない
- **グロスは初出の話が所有する。**並行訳では後の話の担当が「初出」と思ってグロスを付けがち（498 の四国 → 497 へ移動、510 の本州 → 500 にあるので削除、442 の山小屋 → 437 にある）。バッチ後にグロス語を grep する
- **同じ原文見出しは最初の話の訳に揃える**（492「不幸の連続」→ 490 の One Blow After Another）
- **同じ金額のドル換算は話をまたいで揃える**（350 と 351 の3万円が $250 / $240 に割れていた → 240）
- 監督役の後からの英語修正は、逆翻訳ファイルに「監修注（後から変更・ブラインドではない）」として追記する
- **同じアークに同じイニシャルの男女がいて紛れる場合は、一方に -chan を残して書き分ける**（著者の判断、2026-10-01）。山小屋編の Kちゃん（464・478）＝ K-chan、Kくん（450・486〜488）＝ K
