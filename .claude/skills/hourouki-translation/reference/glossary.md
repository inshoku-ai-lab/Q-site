## 2. 人物

イニシャル匿名（Ｍさん等）は**敬称を付けず英字1文字**。"Mr. M" にしない。

| 日本語 | 英語（固定） | 備考 |
|---|---|---|
| ガンドルフ (134) | Gandalf | 長期滞在のヒッピー。複数アークに再登場する主要人物 |
| Ｍさん / Ｃさん / Ｆさん / Ｇくん | M / C / F / G | 敬称なし。初出で誰かを一言添える |
| **Ｉちゃん / Ｉさん** | **I-chan / I-san**（例外） | ⚠️ **"I" は英語の一人称と衝突する。**<br>"I was listening to I talk" は意味不明になる。<br>**Iだけは敬称を残して固有名詞と分かる形にする。**<br>同じ理由で **A**（冠詞）も要注意 → A-san |
| **Ａくん**（Ep 40〜） | **A-kun**（例外） | ⚠️ 同じ衝突。素の "A" は英語の冠詞と区別がつかない。<br>敬称を残す。Ep 40 で初出 |

### 匿名イニシャルの既知の問題（解決不能・許容する）

混成パネル3人全員が指摘したが、**いずれも直せない**。理由を残しておく。

1. **敬称の不統一** — 他は素のイニシャル（N, J）なのに Iちゃん だけ `I-chan`。
   → **統一できない。** `I` 単独は英語の一人称と区別がつかない。不統一は許容する。
2. **同じイニシャルが別人を指す** — Ep 360 の J君（フランス人アーティスト）と
   Ep 465 の Jさん（山小屋の同僚）は**別人**だが、どちらも `J`。
   → **原文がイニシャルを使い回している**（著者の匿名化方針）。
   日本語読者も同じ状況で読んでおり、訳者が letters を振り直すのは原文の改変。
   **アーク文脈カードの人物欄に必ず「このアークのJは誰か」を書く**ことで、
   翻訳時の取り違えだけは防ぐ。

> 査読者は「J と I-chan は同一人物だから統一しろ」と**2ラウンド連続で全員一致**したが、
> **2回とも誤り**。査読者はシリーズ文脈を持たないので人物の同定ができない。
> 人物に関する指摘は必ずこの表と照合してから採否を決める。
| 〜おじさん | the old guy / the older guy | **血縁ではない**。"uncle" は誤訳 |
| 母 | my mother | 「お母さん」でも英語は my mother で統一 |
| エホバの証人 (153) | Jehovah's Witnesses | 教団名。個人は "a Jehovah's Witness" |

## 7. 円→ドル換算レート（年代別）

**その時代のレートを使う。** 現在のレートで換算すると金額感が壊れる。

| 年代 | 概算レート | ¥1,000 ≈ |
|---|---|---|
| 1997–2002 | ¥120–130 / $1 | $8 |
| 2003–2007 | ¥110–120 / $1 | $9 |
| 2008–2012 | ¥80–100 / $1 | $11 |
| 2013–2015 | ¥100–120 / $1 | $9 |
| 2016–2020 | ¥105–110 / $1 | $9.5 |
| 2021–2023 | ¥110–145 / $1 | $8 |

- 換算は**概算でよい**。"about a dollar" / "roughly eight bucks" のように丸める。
- 端数まで出すと嘘くさい。`$1.23` のような精度は使わない。
- 原文が「◯ルピー（◯円）」と二重表記している場合は、**円を経由せず直接ドルへ**。

## 8. 追記のルール

1. 新しい固有名詞・繰り返し語が出たら、**訳す前に**この表に足す。
2. 一度決めた訳語は変えない。変える必要が出たら、**過去の全話を洗い直す**前提で判断する。
3. 人物名は「初出のアーク」も記録しておくと、再登場時に照合できる。
