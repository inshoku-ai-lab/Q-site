## 7. 円→ドル換算レート（年代別）

**その時代のレートを使う。** 現在のレートで換算すると金額感が壊れる。

| 年代 | 概算レート | ¥1,000 ≈ |
|---|---|---|
| 1997–2002 | ¥120–130 / $1 | $8 |
| 2003–2007 | ¥110–120 / $1 | $9 |
| 2008–2012 | ¥80–100 / $1 | $11 |
| 2013–2015 | ¥100–120 / $1 | $9 |
| 2016–2020 | ¥105–110 / $1 | $9.5 |
| 2021–2023 | ¥110–145 / $1 | $8 |

- 換算は**概算でよい**。"about a dollar" / "roughly eight bucks" のように丸める。
- 端数まで出すと嘘くさい。`$1.23` のような精度は使わない。
- 原文が「◯ルピー（◯円）」と二重表記している場合は、**円を経由せず直接ドルへ**。

3. 人物名は「初出のアーク」も記録しておくと、再登場時に照合できる。
