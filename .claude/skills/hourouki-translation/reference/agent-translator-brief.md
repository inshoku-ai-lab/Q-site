# 翻訳エージェント作業指示（サブエージェント経路）

**ワークフロー経由が使えないときの代替経路。** 2026-09-05、ワークフロー内エージェントの
ツール呼び出しがハーネス側の不具合で全て弾かれ、39話が全滅した。通常のサブエージェントは
影響を受けていないため、こちらで回す。1話につき1エージェント（ワークフローは7エージェント
必要だったので、コストも約1/7になる）。

呼び出し側は、この文書を読ませたうえで **ep / arc / part / total** だけを渡せばよい。

---

## 0. 最初にツールの疎通を確認する

```bash
head -3 <sourcePath>
```

**これが権限エラーやスキーマエラーで失敗したら、そこで停止して報告する。**
原文が読めない状態で記事を書けば全文が捏造になる。**絶対に書かない。**
（この判断は過去に実際に39話ぶん正しく機能した。迷わず止めてよい。）

## 1. 規則を読む

自分の語感より、この3つが優先される。

1. `reference/voice-bible.md`
2. `reference/glossary.md`
3. `reference/translationese.md`

## 2. 4パスすべてを順に行う

**① 翻訳** — ボイスバイブルに従う。要点：原文の1文1段落のリズムを保つ。原文に無い事実・
情景・強調を足さない。暗い内容や不快な内容を和らげない。度量衡は初出でメートル法と
ヤード・ポンド法を併記。円は初出でその年代のレートで概算ドルを併記。

**② 対訳監査** — 日本語と自分の英語を突き合わせ、次を探して直す：節の脱落、捏造、
誤訳、皮肉やユーモアの平板化、数値の相違。

**③ ブラインド査読** — **日本語を完全に脇に置き、英語だけを読む。** アメリカの読者、
英国・コモンウェルスの読者、非ネイティブの流暢な読者、の3人として順に読む。
**3人中2人以上が引っかかった箇所だけを直す。1人だけの指摘は採用しない。**
（単独の査読者は過剰修正する。この2/3規則は実際に何度も過剰修正を防いでいる。）

**④ 統合** — ②の修正と③の合意箇所を反映する。**正確さと自然さが衝突したら正確さを取る。**
原文が支えない語句を入れない。

## 3. 機械的な決まり

- **末尾のナビは全部落とす。** 最初の `前の記事`／`次の記事` リンクから
  ファイル末尾までがナビ。**行頭がリンクでない地の文の「次の記事」への言及は本文なので残す。**
  ナビは1行のこともあれば、括弧がエスケープされURL途中で改行して3行のこともある。
- `つづく。。。` → `To be continued...`
- **画像は1枚残らず、同じ位置に置く。** URLは
  `https://qryptraveller.com/...` または `https://qryptraveler.com/...`（**l が1つの誤記が実在する**）
  を `/images/wp/...` に書き換える。**代替テキストは空 `![](...)` のままにする。**
  画像を見ていないので、書けば必ず捏造になる。実物を見る専用パスが後で埋める。
- **会員限定マーカー**：原文に `ここから会員限定` があれば、**同じ位置**に
  `<callout icon="🔒">Members only from here</callout>` を置く。
  直後の `(Reproduction of the content below is prohibited. Legal action will be taken.)` は、
  **原文に「（以下内容転載禁止、法的対処有。）」がある場合だけ**入れる（無い話が実在する）。
  ⚠️ 位置がずれると有料記事が無料で表示される。必ず確認する。
- WordPressの残骸 `\[blogcard url="..."\]` は本文ではない。訳さずに落とす。
- Notionの残骸 `\_` `\*` は記号ではなく保存時のゴミ。英語に持ち込まない。
- 外部リンク（qryptraveller.com 以外。YouTube・Wikipedia等）は**内容なので残す**。
  URLは変えない。行に単独で置かれた裸のURLはそのまま単独行で残す。
- **1文1段落を空行で区切る。** 見出しは原文のレベルを保つ。

## 4. 出力（3ファイル）

`<scratchpad>/agent-out/` に書く。

| ファイル | 内容 |
|---|---|
| `ep-NNN.body.md` | 英語本文のみ。フロントマター・注釈なし。最初の見出しから始める |
| `ep-NNN.excerpt.txt` | 英語30〜50語の要約。感嘆符なし、結末を明かさない |
| `ep-NNN.backtrans.md` | **英語だけを見て**日本語へ訳し戻したもの。原文は見ない。<br>意味を補わない。英語が曖昧ならその曖昧さを残す |

逆翻訳は著者の検証用。著者は英語の自然さを判断できないと明言しており、
**日本語の訳し戻しだけを読んで意味のズレを確認する。**

## 5. 報告すること

- 原文の内容行数（ナビ除く）と英語のブロック数、その差の理由
- 画像の枚数（原文／英語）
- 会員限定マーカーの有無と、原文・英語それぞれのブロック位置
- 統合パスで何を採り、何を退けたか（各1行程度）
- **新しい固有名詞が出たら報告する。** `glossary.md` は自分で編集しない
  （他の話を担当するエージェントと衝突するため）。呼び出し側がまとめて追記する。
