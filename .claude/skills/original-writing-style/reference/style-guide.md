# 文体ガイド

GSが参照指定した以下の記事群から抽出した文体的特徴。**書く前に必ず読み返すこと。**

分析対象：
- 「トランプ氏暗殺未遂犯、ベム・ミラー氏の正体に迫る！」（2024-10）
- 「なぜクリプトラベラーは名前からQの文字を取り除いたのか？」（2024-10）
- 「マウイ島火災、ハワイ王国の真相とスマートシティ計画」（2023-08）
- 「『サウンド・オブ・フリーダム』の出資者は、DSとズブズブの人物？！　徹底検証してみた件」（2023-07）
- 「迫りくるグレートリセット、危機をチャンスに変える対策方法７つ　【前編】【中編】【後編】」（2023-04）

---

## 1. 一人称は記事タイプで使い分ける（重要）

GSの記事には「僕」の記事と「私」の記事の両方が実在する。

| 記事タイプ | 一人称 | 実例 |
|---|---|---|
| 真相考察・検証・情報戦・個人的な話 | **僕** | ベム・ミラー、マウイ、サウンド・オブ・フリーダム、Q改名、支配層の罠 |
| 資産防衛・経済・実務的アドバイス | **私** | グレートリセット対策7つ、貴金属没収対策記事 |

**ただし銀・貴金属に関する記事は、内容が検証型であっても例外なく「私」で統一する**（GS指定）。
「没収の歴史」シリーズ、銀の実務知識、資産防衛カテゴリの記事はすべて「私」。迷う余地はない。

「僕」を使うのは、銀・資産防衛以外のジャンル（真相論・情報戦・個人的な話）を書くときのみ。

## 2. 冒頭の型

```
皆さんこんにちは、クリプトラベラーです。
```

から入るのが基本。ただし記事のテーマに合わせて肩書きを足すことがある：

> 皆さんこんにちは、**メキシコの山奥で自給自足の生活を目指している**クリプトラベラーです。

続けて、その記事を書くに至った経緯・きっかけを説明する。
「先日に〜という記事を書きました」「〜との噂が立っています」「〜が大きな注目を集めています」。

そして「この記事では〜していきます」と宣言して本題へ。

## 3. 文の長さ・リズム（最重要）

**ほぼ一文一段落。** 改行が非常に多い。複文・重文を避け、短い単文を積み重ねる。
一般的なAIが書く「3〜5文で1段落」とは対照的で、これが一番目立つ特徴。

> ですが、これは２０２３年５月にチリで起こった出来事で、レーザー光線はビデオ編集で付け足されたものであることが証明されています。
>
> こちらの画像は実際の今回のハワイの火事の画像ですが、AP通信の写真を加工したものであることが分かっています。
>
> 上記の画像は、何者かが何らかの意図で、意図的に即座に作成したものです。

**数字は全角の漢数字・全角数字を混在させる。** 「２０２３年」「５年前」「８０％」「７つ」など全角が多いが、
西暦や固有名詞では半角も使われる（「2015年」「99.99999999%」）。厳密な統一ルールはないので、
既存記事のゆらぎをそのまま受け入れてよい。

## 4. 検証プロセスを「実況」する

これがGSの記事の説得力の核心。結論だけでなく、**自分がどう調べたかを手順として書く。**

> ツイッターの動画をよく見てみると、古い感じの映像で、インタビューのセットにFOXの文字が見えました。
>
> この映画は5年前に完成しているので、その直後のFOXでのインタビューかもしれません。
>
> YouTubeで、「FOX sound of freedom interview」で検索し、出て来た動画を時系列に並べて、古いものを辿っていくことにしました。
>
> そして、出て来たのが5年前のインタビューです。

読者が同じ手順を再現できるレベルで書く。検索ワードまで書く。

## 5. 自分の間違いも書く

信頼を作る重要な技法。取り繕わない。

> ちなみに、これには僕も飛びついてしまいました。
>
> 反省点ですね。

## 6. 判定を明示し、暫定であることも明示する

グレー領域を扱うので、「白か黒か」を自分の言葉で判定する。同時にそれが暫定であることも書く。

> 僕はここでは、デジョリア氏に関しては、完全な真っ黒ではなく、黒の可能性が大いにある灰色と判断します。
>
> 今後の情報次第で、この判断は変化しますが。

確率で述べることも多い：

> 僕個人としては、現時点では８０％くらいの割合で、視点４が正解なのではないかと考えています。

## 7. 「両方の視点で考察する」という明示的な方法論

GSの記事の骨格。**必ず対立する2つの視点を立て、それぞれを本気で検証してから統合する。**

```
## DS側だという視点
## DSではないという視点
## 両サイドを合わせた視点
```

統合パートでは「どちらの視点に立っても確実に言えること」を先に列挙し、
そのうえで両方の可能性を含んだ結論を出す。

> なので、両方の可能性を含有した結論を出すのが的を射ているかと思います。
>
> つまり、**「この映画は後になって誤誘導される可能性があるものの、トランプ陣営に支持されており、大衆を大量に覚醒させている映画」**だということです。

## 8. 太字・「・」の箇条書きまとめ

論点の再整理には、必ずこの形式を使う。**行全体を太字にする。**

```
**・バンディ家は本気でDSと戦っている**

**・ミラー氏が監督したドキュメンタリー映画の情報の多くが真実の可能性が高い**
```

各項目の間に空行を入れる。

## 9. 「点と点をつなぐ」メタファー

読者に自分で結論を出させるための頻出フレーズ。

> 沢山の点を書き出してみましたが、点と点は繋がりましたでしょうか？
>
> 点が繋がれば、・・・・・・・・・・と線になってきます。
>
> 繋がった線はどこを指しているのでしょうか？
>
> あえて結論を書かずにおきますが、みなさんが同じような結論になっているのでは無いかと思います。

**結論をあえて書かずに読者に委ねる**のは、GSの重要な締め方の一つ。

## 10. 読者への問いかけで判断を委ねる

> 皆さんはこの言い訳をどう感じるでしょうか？
>
> さて、これらの要素を見て皆さんはどのように考えますか？

## 11. 「考察の限界」を最後に置く

長い考察記事では、末尾近くに自分の考察の限界を明示するセクションを置くことがある。

> 最後になりますが、この記事は飽くまでも僕個人の身勝手な考察です。
>
> 見落としている視点の方が多いでしょうし、全くの予想外の展開になることも十分にあり得ます。
>
> また傾向として考察や予測は外れることの方が圧倒的に多いです。
>
> なのでこの記事は参考程度に捉えて、ご自身の思考のインスピレーションにしていただけると幸いです。

## 12. 見出しは短く、数を多く

`## 罠の可能性` `## 検証` `## 確実な黒` `## アドレノクロム` `## サイレンがならなかった`
`## 極めつけの情報、ハワイ王国の真相`

体言止め・短い名詞句が中心。1見出しあたり数百字で次の見出しへ。

対策・方法を列挙する記事では**全角数字＋全角スペース**の見出しにする：

```
## １　情報通になる
## ２　田舎に逃げ道を作る
## ３　食糧不足に備える
```

## 13. 語彙・世界観フレーム

地の文に自然に登場する語彙：

`支配層` / `DS（ディープステート）` / `ホワイトハット` / `情報戦` / `五次元チェス` / `覚醒` /
`グレート・アウェイクニング` / `誤誘導` / `工作員` / `クリックベイト詐欺師` / `コントロールド・オポジション` /
`羊さん` / `資産防衛` / `両建て` / `辻褄が合う`

強調・つなぎ：`ズバリ` `はっきり言って` `残念ながら` `正直` `もちろん` `というのも` `というわけで`
`〜な訳ですが` `まぁ` `〜って感じですね`

軽い口語が混ざる：「〜だし」「〜なんてものではなくて」「ものすごい」「半端ない」「ガチで」

## 14. 絵文字を控えめに使う

文末に軽く添える程度。多用はしない。

> もちろん、ただの偶然でしょうが💦
>
> それではまた次の記事で☺️🙏✨

## 15. 引用・リンクの形式

- 外部リンクは `[blogcard url="https://..."]` のショートコード（`ArticleBody.astro`がカードに変換）
- 人物名にインラインリンクを付ける：`[ジョーダン・セイサー氏](https://x.com/Jordan_Sather_)`
- ツイート/YouTube/TikTokはURLを単独行に置くと埋め込みになる
- 引用は `>` のブロッククォート。他者の発言を引くときはこれ
- 画像は `![](/images/wp/wp-content/uploads/...)` でキャプションなしに挟む

## 16. 結び

以下を組み合わせる：

1. 「長々と最後までお読みいただき、ありがとうございました。」
2. 収益源の明示（率直に書く。隠さない）：
   > 僕の執筆活動は、こちらの【銀投資専門店】の利益で支えています。
   >
   > 経済崩壊の可能性に備えつつ、応援してもらえると嬉し限りです。

   **※ 現在は `/silver` ページへのリンクに置き換える**（旧サイトのリンクは使わない）
3. 拡散のお願い：「ぜひSNSなどでシェアして情報の拡散のご協力をよろしくお願いします。」
4. 関連記事を `[blogcard url="..."]` で数本並べる

## 17. タイトルの型

- 「〜の正体に迫る！」
- 「〜？！　徹底検証してみた件」
- 「〜、危機をチャンスに変える対策方法７つ　【前編】」
- 「なぜ〜なのか？」

全角の `？！`、全角スペース、`【】` を使う。感嘆符・疑問符で煽ってよい。

## 18. やってはいけないこと（AIが陥りがちな失敗）

- **3〜5文をひとまとめにした「教科書的な段落」を書かない。** 1〜2文で改行する。これが最重要。
- **結論だけを書かない。** どう調べたか、何を見て何を確認したかのプロセスを書く。
- **一方向の主張で押し切らない。** 必ず反対の視点も立てて検証する。
- 「〜とされています」のような責任の所在をぼかす受け身文体に流れない。自分の判断として書く。
- 学術論文のような脚注（[1]など）を使わない。`[blogcard url="..."]`かブロッククォートで。
- 完璧に整った優等生的な文章にしない。「まぁ」「〜って感じですね」「反省点ですね」のような
  ラフさ・自己開示が入って初めてこの文体になる。
- **銀の購入代行に関する記事で、法的な断定をしない。** MLATの壁やハードルの高さは強調してよいが、
  「情報が絶対に渡らない」という言い切りは避ける（一次法律調査で指摘済み。
  `ARCHIVE-FOR-BUSINESS-OS.md` 第6節参照）。
- **NESARA/GESARA・Q関連の情報は扱わない。** 前者はGSが根拠のない詐欺的陰謀論と判断しているため、
  後者はGS本人が書く領域のため。金本位制回帰は扱ってよい。
