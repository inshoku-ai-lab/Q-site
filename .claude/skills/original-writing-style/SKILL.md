# GSオリジナル記事 文体再現スキル

## 使うタイミング

GS（サイト運営者・クリプトラベラー）名義で**新規に**（＝翻訳ではなく）記事を書くとき。
現在の主用途は「資産防衛」カテゴリ・シリーズ「没収の歴史」（銀の購入代行の差別化コンテンツ）だが、
今後ほかのオリジナル記事にも流用してよい、GS本人の文体を再現するための汎用スキル。

**翻訳記事（`devolution-translation`スキルの対象等）には適用しない。** あちらは原著者の世界観・文体を
そのまま訳出することが目的で、このスキルとは目的が逆になる。

## 大前提

- **これはGS本人になりきって書く作業。** 「〜と考えられます」のような第三者的な解説調ではなく、
  「私は〜と考えています」という一人称の語りを基本にする。
- **文体の詳細は `reference/style-guide.md` を必ず読んでから書き始める。** 特徴を捉えずに一般的な
  「わかりやすいブログ文体」で書くと、既存記事と地続きに読めない。
- **断定より確率的な語り。** 陰謀論・歴史的類推を扱うジャンルなので、「〜だ」と言い切るより
  「〜でしょう」「〜のではないでしょうか」という留保を伴う語りが一貫して使われている。
  ただし留保しつつも論旨は明確に押し切る、というバランスを保つ（歯切れの悪い両論併記にしない）。
- **事実の正確性はGS本人の判断を優先しつつ、法律・規制に関わる断定は避ける。** 銀の購入代行に関する
  記事では、CLAUDE.md相当の恒久的制約（個別の投資助言をしない、断定的な法的主張は避ける）が生きている。
  史実・過去の政府文書は一次資料ベースで正確に。将来予測・政府の意図の考察は「〜と考えています」
  「〜かもしれません」の推測トーンを保つ（これは弱さではなく、この文体の一貫した型）。

## ワークフロー

```
見出し構成の確認 → 本文執筆（style-guide.mdに従う）→ excerpt作成 → Notionへ投入（Draft）
    → GSレビュー待ち → GS承認後にStatusをPublishedへ
```

1. **見出し構成をまず出す**（このセッションでやったように、章立てだけ先に提示してGSの確認を取る）。
   いきなり全文を書き始めない。承認された構成に沿って本文を書く。
2. 本文は `reference/style-guide.md` の型に従って執筆。
3. `reference/article-template.md` のNotionプロパティ雛形に沿って、`mcp__Notion__notion-create-pages`
   でBlog Articles DBに直接ページを作成する（ローカルmdファイルは作らない — このサイトの本番コンテンツは
   Notion側が正であり、`npm run sync`でサイトに反映される）。
4. **新規記事のStatusは必ず `Draft` にする。** GSが確認して問題なければGS自身が`Published`に変更する
   （このスキルの実行者が無断でPublishedにはしない）。
5. タグ・カテゴリ・シリーズの付け方は `reference/tag-rules.md` を参照。

## 参照ファイル

- `reference/style-guide.md` — 文体・構成・語彙の詳細分析とチェックリスト
- `reference/article-template.md` — Notionページ作成時のプロパティ雛形
- `reference/tag-rules.md` — カテゴリ・シリーズ・タグの付与規約

## 分析対象にした記事（サンプル）

- 「なぜクリプのところで銀を買うと政府による貴金属没収から守られるのか？」（資産防衛の核記事）
- 「なぜ今、銀なのか？　銀の現物が枯渇している５つの表の理由と３つの裏の理由」
- 「支配層が編み出した、覚醒者を誤誘導する罠とは？　その対策方法５つ」
- 「偽ユダヤと偽イルミナティの話」

新しいオリジナル記事を書くたびに、可能であればNotionの「オリジナル記事」既存タグが付いた記事を
1〜2本読んでから書くと精度が上がる（文体は経年で微妙に変化している可能性があるため、直近の記事を優先）。
